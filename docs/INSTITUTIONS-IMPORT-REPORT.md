## How the source maps to Academicall

- **Institution** = `Institution` column (official name kept exactly; abbreviation, type, category, ownership, state stored).
- **Faculty** = `Faculty / School (IBASS group)`. These are JAMB IBASS groupings (e.g. SCIENCES, NCE programmes), not always the institution's own faculty names. Stored with `kind` = ibass_group / programme_group / unassigned.
- **Department** — the source has no department column. Each programme is filed under a department with the same name, marked `derived = true`, so the four-step selection still works. Replace with real departments when an institution supplies them.
- **Program** = `Programme` (status, duration, UTME subjects, award type kept).
- **University of Abuja** keeps its curated Academicall catalog and the id `uofa`; every existing UofA user, feed post, class and membership is linked to it by migration.
